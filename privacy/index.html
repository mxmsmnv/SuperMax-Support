Privacy Policy

Effective October 16, 2026

SuperMax is a bring-your-own-provider iPhone assistant. It does not require a SuperMax account, include advertising, or use developer analytics or tracking.

Information stored on the device

SuperMax stores chats, schedule data, preferences, configured service URLs, and connection state locally on the device. API keys, GitHub tokens, and bearer tokens are stored in the iOS Keychain. Temporary audio recordings are protected on the device and removed after transcription or when the recording is discarded.

Information sent to services selected by the user

SuperMax sends information off the device only when needed for a feature the user chooses:

  • Message text, attached images or files, and audio may be sent to OpenRouter or another OpenAI-compatible provider configured by the user.
  • Text may be sent to xAI when the user selects xAI Text to Speech.
  • Speech may be processed by Apple’s Speech service when Apple transcription is used.
  • GitHub account and repository information is exchanged with GitHub when the user connects GitHub, selects a repository, reads repository content, or confirms a supported write action.
  • Server information and protocol requests are sent to an MCP server or legacy gateway URL configured by the user.

Those services process information under their own terms and privacy policies. SuperMax does not control their retention practices. Users should avoid sending sensitive information to a provider unless they trust that provider and its configuration.

Permissions

SuperMax may request microphone and speech-recognition access for voice input, camera or photo-library access for attachments, file access for a file selected by the user, motion access for non-blocking movement context, and Live Activity or background-audio capabilities for an active voice session. The app does not use motion information to hide or block features.

Data received by the developer

The developer does not operate a SuperMax account service and does not receive the user’s chats, recordings, files, provider credentials, GitHub tokens, or repository contents through the app. If a user voluntarily contacts support, the developer receives the information included in that support request.

User choices and deletion

Users can disconnect configured services, remove stored credentials, clear or delete chats, and delete local app data by removing the app from the device. Data already sent to a selected third-party service is governed by that service’s deletion and retention controls.

Children

SuperMax is a general productivity tool and is not directed to children under 13.

Changes

This policy may be updated when SuperMax adds or changes a data-handling feature. The effective date above identifies the current version.

Contact

For privacy or support questions, contact maxim@smnv.org.
