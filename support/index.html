Quick fixes

VO

Voice and speech

Confirm microphone and speech recognition access in iOS Settings. Also check that another app is not actively using the microphone.

AI

AI provider

Open Settings → Artificial Intelligence and verify the active provider, API key, selected model, and connection status.

GH

GitHub connection

After approving the device code, return to SuperMax and tap I approved — finish connection if authorization does not finish automatically.

BG

Background and CarPlay

An active recording can continue in the background. Force quitting, restarting the device, or system termination ends the session.

Connection checklist

Verify the full path

  1. Confirm the required iOS permission for the feature you are using.
  2. Open the corresponding SuperMax settings screen and verify its status.
  3. Check that the selected third-party account, API key, model, or server is active.
  4. Retry the action and capture the exact message if it still fails.
Protect your credentials. Never include an API key, OAuth token, password, or private repository content in a support message.
