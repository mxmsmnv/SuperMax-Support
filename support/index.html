SuperMax Support

Help for SuperMax on iPhone and CarPlay.

Before contacting support

  • Confirm microphone, speech recognition, camera, and photo permissions in iOS Settings when using the related features.
  • In SuperMax, open Settings → Artificial Intelligence to verify the active provider, API key, and selected model.
  • GitHub uses device authorization. After approving the code, return to SuperMax and tap I approved — finish connection if the app has not completed automatically.
  • xAI voice and other cloud services require a valid account and API key from that provider.
  • An active recording can continue while the app is backgrounded, but it ends after a force quit, device restart, or system termination.

Contact

Email maxim@smnv.org and include the SuperMax version, iOS version, device model, the screen where the issue occurred, and the exact error message.

Never send an API key, OAuth token, password, or private repository content.
